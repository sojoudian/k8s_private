## Technical Details
- Browser: Claude in Chrome on the device that the user named. The session opened the test link in a new tab,
  read the instructor view (Content and Settings), and closed the tab at the end.
- Extraction: the page text gives each question, each option and a "Correct answer" mark after each correct
  option. A DOM check confirmed the marks: 63 marks in total, and the five True/False lists have the mark on
  False, False, True, False and True (Q2, Q15, Q17, Q22, Q35).
- The browser tool blocked a direct output of the parsed data, because the text has `key=value` parts (for
  example `--port=18080`). So the text was transcribed from the page-text extract into
  `scratchpad/summer_exam/exam.json`.
- Verification: a script in the page computed a SHA-256 checksum of each question (the stem, the options and
  the correct-answer marks, with whitespace normalized). A local script computed the same checksum from the
  transcribed data. Result: 40 of 40 agree. The page text has ASCII characters only.
- The Markdown file is generated by a script (`scratchpad/summer_exam/make_md.py`) from the verified data, so
  the file has no hand-typed question text.
- The type labels come from the options: True/False when the options are True and False; "more than one
  correct option" when more than one option has the mark.
