## 2. The design-system engine — two topologies in one repo

**Share-by-copy (11 files).** Each of the 11 older renderers defines the full palette, the
fonts, the canvas, and the helper set in its own file. The values agree. The code does not.

**Share-by-import (3 files).** `build_week12_v3_lab.py:18`, `build_week13.py:19`, and
`build_week14.py:19` import the palette and the helpers from `build_week12`. These three
cannot drift.

The 18 core colour tokens are identical in all 11 definers. `build_week03.py` differs only by
trailing comments. Two real differences exist:

- `build_week12.py` does **not** define `ALERT_RED`. The other 10 do.

  `build_week12.py:42`. `DESIGN_LANGUAGE.md` does not list this colour.

### 6.5 Lab content validity — the Terraform is dead

`terraform init` was run on a copy of `week05_practical_work/week5_code/`. It **failed**.

```
Downloading registry.terraform.io/terraform-aws-modules/security-group/aws 6.0.0 ...
Error: Unsupported argument
  on sg.tf line 8, in module "dev_ssh_sg":
   8:   ingress_cidr_blocks = ["127.0.0.1/32"]
An argument named "ingress_cidr_blocks" is not expected here.
```

`sg.tf` pins no version. The module therefore always resolves to the newest release, and
release 6.0.0 removed `ingress_cidr_blocks`, `ingress_rules`, and `egress_rules`. A student
cannot get past `terraform init`. `terraform fmt -check` passes, so the failure is semantic,
not a syntax error.

Eight more defects sit behind that one. Each was verified with a command.

1. **A zero-width space corrupts the bootstrap.** `ec2.tf` line 33 holds U+200B at byte 905,
   directly after `kind create cluster --config kind.yaml`. The command breaks on the host.
2. **A zero-width space corrupts the node image.** `kind.yaml` line 5 holds U+200B at byte
   180, at the end of the image digest.
3. **A referenced file is missing.** `ec2.tf:54` reads `${path.module}/week5.pub`. That file
   does not exist. `terraform apply` fails.
4. **The security groups collide.** `sg.tf:4` and `sg.tf:15` both set `name = "ec2_sg"`. AWS
   rejects two security groups with one name in one VPC.
5. **SSH is open to the world.** `sg.tf:19` sets `ingress_cidr_blocks = ["0.0.0.0/0"]` with
   `ssh-tcp`.
6. **`kind.yaml` never reaches the instance.** The `user_data` block calls
   `kind create cluster --config kind.yaml`, but nothing uploads that file.
7. **The key pair has no dependency edge.** `ec2.tf:46` sets `key_name = "week5"` as a
   literal string. The key pair is created at `ec2.tf:53`. Terraform cannot see the order.
8. **`init_kind.sh` cannot execute.** Every line is indented four spaces, so `#!/bin/bash`
   starts at byte 4. The kernel does not read that as a shebang.

`kubia-manual.yaml` is valid. `config.tf` and `output.tf` resolve.

**Nested duplicate.** `week05_practical_work/week5_code/week5_code/` holds a second copy.
Six of the seven files are identical. `kind.yaml` differs: the inner copy pins the older node
image `v1.19.11`.

**Stack age.** The AMI filter selects Amazon Linux 2. kind is pinned to v0.11.0 (2021). The
node image is v1.23.17. All three are far behind the 2026 course material.

## 10. Bottom line

The build system is healthier than the previous analysis claimed. Thirteen of the fourteen
renderers reproduce their stored deck exactly. Every builder emits correct footers. Only one
builder emits float coordinates, and a fifteen-line function removes them. The two builders
that fail need three replacements each, and this run proved both repairs.

The damage has moved downstream. The defects that reach students no longer come from the
Python. They come from three habits:

1. A person splits or trims a deck inside PowerPoint. The footers then lie. This produced the
   `/39`, the `/71`, the `finalWork/Week04.pptx` `/38`, the lost hidden slide, and the five
   slides that appear in both Week06 parts.
2. The course schedule is written out by hand in four places. All four disagree.
3. The lab infrastructure was pinned to nothing. It has now rotted to the point where
   `terraform init` fails before a student reaches the first lesson.

   unblocks the entire Week-05 lab.

   these every week.

   through it. The repaired file is ready.
