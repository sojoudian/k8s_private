## 2. Design-system engine (architectural heart — unchanged core)

Every builder re-declares the same engine inline; canonical reference `build_week05.py`. **Verified identical across all 10:** `BLUE #1FA8E0`, `SLATE #37465A`, `WHITE #FFFFFF`, `FONT_SANS='Calibri'`, `FONT_MONO='Consolas'`, `STEPS[6]` blue→slate ramp. Canvas `13.333×7.5in`, blank `slide_layouts[6]`, absolute positioning.

**Coordinate-safety primitives (the signature artifact):** `_i(v)` int-coerces floats at every shape call site; `_sanitize_coords(prs)` walks `off/ext/chOff/chExt` and integer-coerces before save. **Why:** Python `/` yields a float; `python-pptx` serializes it as e.g. `"4288536.0"`; **PowerPoint & Keynote parse that as 0 and teleport the shape to (0,0)**; LibreOffice tolerates it, so the project's own JPG-render QA is blind to the bug.

**New palette addition (week08/09 only):** `EXAM_RED = #FF6B6B` (week08:49, week09:52) — a purposeful off-primary accent for the exam-week tile in `course_outline`. `GOAL_GREEN #27AE60` / `ALERT_RED #E74C3C` are carried forward but **defined-and-unused** (dead) in week08/09.
